# Structure-Aware HTML Extraction Agent

学源滔滔高校专家数据提取 Agent 技术方案，静态 GitHub Pages 文档。

## 发布

1. 创建 GitHub 仓库 `html-extraction-agent`。
2. 将 `index.html` 上传至仓库根目录。
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save。
4. 页面地址通常为 `https://laiwenai.github.io/expert-search-research/html-extraction-agent/`。

当前仓库内容为技术方案文档，不包含已实现的生产 Agent。
